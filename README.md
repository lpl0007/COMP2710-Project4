# COMP 2710 Project 4 — Trivia Quiz

A C++ trivia quiz application built around a dynamically allocated linked list. The project emphasizes data structures, modular function design, conditional compilation, and unit testing.

## What I Built

- Implemented a `TriviaNode` structure containing a question, answer, point value, and pointer to the next node.
- Built and managed a linked list of trivia questions using dynamic memory allocation.
- Implemented functionality for adding trivia questions and running the quiz.
- Added answer validation and score tracking.
- Implemented unit tests covering normal, boundary, and invalid-input cases.
- Used conditional compilation to maintain separate testing and product versions.

## Concepts Demonstrated

- C++ pointers and dynamic memory
- Linked-list data structures
- Strings and user input
- Functions and modular program design
- Conditional compilation with `#ifdef`
- Unit testing and boundary-case testing
- Basic memory-management practices

## Technologies

- C++
- Standard C++ libraries
- `assert()` for testing
- Preprocessor directives

## Project Context

This project was completed for Auburn University's COMP 2710 (Software Construction) course. It demonstrates core software-construction practices applied to a small interactive application.
